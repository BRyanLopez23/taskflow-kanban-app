# ⚡ TaskFlow Pro — Agile Kanban & Project Tracker (`JavaScript ES6+ OOP + Responsive UI`)

Aplicación web interactiva para gestión ágil de proyectos (Scrum / Kanban), seguimiento de tareas por estado (`Backlog`, `In Progress`, `Done`), cálculo de métricas de productividad en tiempo real y exportación de datos en formato **JSON**.

Desarrollado por **Bryan Francisco López León** ([github.com/BRyanLopez23](https://github.com/BRyanLopez23)) — Software Engineering Student.

---

## 🛠️ Características Técnicas

* **Programación Orientada a Objetos (POO) en JavaScript (ES6+):** Arquitectura modular desacoplada en clases (`TaskItem`, `KanbanStore`, `KanbanController`).
* **Diseño Responsivo Moderno (HTML5 & CSS3):** Interfaz oscura estilo SaaS adaptable a pantallas móviles, tablets y monitores de escritorio mediante CSS Grid y Flexbox.
* **Persistencia y Serialización JSON:** Almacenamiento local automático (`localStorage`) y función de exportación directa a archivos `.json`.
* **Filtrado Reactivo en Tiempo Real:** Búsqueda instantánea por texto, etiquetas (`#tags`) y nivel de prioridad (`HIGH`, `MEDIUM`, `LOW`).
* **Despliegue Directo (GitHub Pages Ready):** No requiere servidor intermedio para su demostración en vivo.
